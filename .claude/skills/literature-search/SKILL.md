# Literature Search

## Workflow
1. Define scope precisely:
- topic, domain, and boundary conditions
- date range and language constraints
- target output size (for example top 10 or top 30 papers)

2. Build query groups:
- core concept keywords
- method keywords
- application/domain keywords
- combine with Boolean variations

3. Screen with explicit criteria:
- inclusion (relevance, novelty, evidence quality)
- exclusion (off-topic, low-quality sources, duplicates)

4. Rank and summarize each paper with:
- citation metadata
- one-sentence contribution
- why it matters for the user's goal
- confidence level if metadata is partial

5. Deliver a shortlist and gap map:
- Top-N must-read list
- thematic clusters
- unresolved questions to guide deeper research

## Guardrails
- Keep a search log (query, date, source, result count).
- Separate verified facts from inference.
- Never fabricate citation details.
