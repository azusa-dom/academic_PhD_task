# 我的医学与 AI 科研绘图工作包

入口是 `$medical-ai-figure-workflow`。写一句任务并提供素材即可，不需要手工填齐本目录。Codex 会提取主张、建立任务合同并执行相应模式。本目录是空白模板，目前没有研究图或实验结果。

## 直接复制调用

新图预览：

```text
使用 $medical-ai-figure-workflow 预览：根据附件/当前目录的正文、图注和参考图制作 Figure 1 方法框架。主张从正文提取。紧凑学术布局，英文图内标签，只给我 PNG 预览。自动完成规划、生成和核对，保存为新版本。
```

只规划：

```text
使用 $medical-ai-figure-workflow 规划：根据这些素材形成主张、panel 结构和箭头关系，标清 observable、latent、assumptions 与 validation boundary，输出工作包，先不生成图。
```

局部精修：

```text
使用 $medical-ai-figure-workflow 精修：基于这张图压缩留白并统一对齐。保留文字和科学关系，保存新版本，给我 PNG 对照预览。
```

真正可编辑：

```text
使用 $medical-ai-figure-workflow 编辑版：将已确认图稿做成 Illustrator AI / SVG / PowerPoint PPTX（选择一种）。文字、框、箭头、连接线及图层需分别编辑，验证保存文件后给我编辑源和 PNG。
```

只审计：

```text
使用 $medical-ai-figure-workflow 审计：检查正文、图注和图是否一致，重点看箭头、测量对象、证据范围和验证目标，列出具体问题与建议，暂不修改。
```

继续：

```text
使用 $medical-ai-figure-workflow 继续：打开 figure_jobs/中的指定任务目录，读取上一版合同、图稿和检查记录，核对实际文件后继续精修。
```

极简调用：`使用 $medical-ai-figure-workflow 预览：根据这个方法段落做一张框架图。`

如果当前会话未列出新 skill，使用：`请读取 /Users/hydra/.codex/skills/medical-ai-figure-workflow/SKILL.md，按这个工作包处理以下素材。` 后续会话可按技能列表实际刷新情况调用。

## 默认设置及覆盖

中文说明、英文图内标签、白底、紧凑布局、克制配色、明确技术对象和箭头。默认交付 PNG；数据图使用可追溯数值，概念图标清示意性质。未指定期刊时使用学术风格估计，命名风格需样本校准。编辑版核对实际文本与图形对象，PNG 生成不代表原生交付。

在请求末尾写 `图内中文`、`单栏宽度`、`只改配色`、`保留所有标签`、`按附件风格` 可以覆盖预设。概念图可以没有患者数据，经验数值必须有来源。

## 工作包文件

| 文件 | 内容 |
|---|---|
| 01_task.yaml | 主张、模式、输入、默认值、修改边界 |
| 02_claims.csv | 主张来源、推断条件、视觉对应 |
| 03_panels.md | Panel 层级、技术对象、箭头关系 |
| 04_caption.md | 图注、证据限制、alt text |
| 05_audit.md | 实际执行的科学/数值/视觉/编辑结构检查 |
| 06_delivery.json | 实际文件及状态，初始是未执行 |

任务在项目下建立独立 `figure_jobs/主题_时间/`，按模式填需要的文件。原始论文、CSV 和图稿保留原状。此简化模板不是 scientific-figure-suite 的 JSON schema，不直接导入它的 memory 工具。

## Cine-CMR 调用例

```text
使用 $medical-ai-figure-workflow 预览：根据附件正文制作 cine-CMR regional strain 方法框架。区分图像证据、材料对应推断、measurement contract、区域输出和验证目标。conditional recoverability 按正文的待验证状态表达。先建立 claim 到视觉的映射，再完成紧凑 PNG 预览。
```

此例不要求每张图固定采用同一结构。按实际任务调用 scientific-figure-suite 做规划与审计，scientific-visualization/nature-figure 做数值图与版式，图像生成做栅格预览，受支持的矢量或原生应用做编辑版。
