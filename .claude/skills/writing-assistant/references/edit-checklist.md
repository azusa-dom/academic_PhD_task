# Edit Checklist

## Sentence Level
- [ ] Remove vague fillers (very, quite, somewhat, etc.)
- [ ] Replace passive voice where clarity improves
- [ ] Keep subject-verb-object clear

## Paragraph Level
- [ ] Topic sentence appears early
- [ ] Evidence follows each claim
- [ ] Transition to next paragraph is explicit

## Manuscript Level
- [ ] Terminology is consistent
- [ ] Tense usage is consistent by section
- [ ] Citations remain attached to the right claims
- [ ] No factual additions beyond source draft
