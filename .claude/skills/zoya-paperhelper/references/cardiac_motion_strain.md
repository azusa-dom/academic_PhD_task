# 领域检查：心脏影像运动与应变

适用于 cine-CMR feature tracking、DENSE、tagging、超声斑点追踪、深度学习运动估计、配准、心肌应变相关论文。

## 分清层次

cine 图像、轮廓一致性、材料点对应、位移、应变是不同层次的量。论文在某一层表现好，不能自动推到下一层：

- 分割 Dice 高 → 只说明轮廓接近，不说明心肌内部材料点对应正确。
- 图像相似性 / 重建误差低 → 只说明变形后图像像，运动可以错（孔径问题、纹理稀少）。
- 轮廓导出的应变与参考一致 → 可能只反映边界运动，不说明区域跟踪信息正确。

## 应变必须写清四件事

每条与应变有关的主张，检查论文是否给出：

1. 定义：Lagrangian / Eulerian、Green–Lagrange / 工程应变 / 对数应变；是一维线应变还是张量分量。
2. 参考态：舒张末期如何确定，各方法是否相同。
3. 心肌层：心内膜、中层、透壁平均。
4. 时相：峰值、收缩末期、还是某一固定时间点；比较双方是否同一时相。

任一项缺失时标为 [未报告]；两种方法在这些项上不同时，它们之间的"不一致"可能部分来自定义差异而非跟踪误差。

## 证据不能互相替代

以下都不是运动准确性的直接证明，只能作为辅助：

- Dice 和轮廓距离；
- 图像相似性指标；
- 与 LGE 的对应（LGE 反映组织特征，与功能异常不必一一对应）；
- 扫描–重扫重复性（稳定 ≠ 准确）；
- 与临床结局或分组的关联。

直接证据层次大致是：有真值的仿真/体模 → 与独立的运动编码成像（DENSE、tagging）在同一切面、同一定义下比较 → 与其他 FT 方法比较（只说明一致，不说明谁对）。

## 全局与局灶

全局或节段平均指标好，不能证明局灶异常的位置、范围或时序准确。评价局灶检测需要：有已知位置/范围的病灶（仿真瘢痕或有参考的在体病灶）、在病灶尺度上的误差、空间定位或范围误差、时序误差。如果论文结论涉及"区域""局灶""定位"，但评价只有全局或 AHA 节段平均，记为路线断点。

## 常见统计单位问题

- 节段数当作独立样本（每人 16–18 个节段）。
- 切面数当作受试者数。
- 训练/测试按切面划分导致同一受试者跨集合。
- 相关系数代替一致性界限；百分比与百分点混用（应变本身是百分数，差值应写百分点）。
