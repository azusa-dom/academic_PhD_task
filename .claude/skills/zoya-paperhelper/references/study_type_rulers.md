# 不同研究类型用不同的尺子

先判断论文类型，再挑出这一类最该问的问题。混合型论文（例如方法开发 + 临床验证）对每部分分别用对应的尺子。报告规范只用来提示"该报告而没报告什么"，不当作评分表；规范的具体条目以官方最新版本为准，引用前核实。

| 类型 | 最关键的三到四个问题 | 相关报告规范（提示用） |
|---|---|---|
| 方法开发（含深度学习） | 划分单位与泄漏；对照是否公平；监督信号/真值从哪来；是否有外部测试 | CLAIM（医学影像 AI）、TRIPOD+AI（预测模型） |
| 验证 / 方法间一致性 | 参考标准误差与独立性；定义是否可比（量、时相、层）；一致性界限而非相关；重复性作为上限 | GRRAS（信度与一致性研究） |
| 诊断准确性 | 谱偏倚；阈值是否预设；参考标准是否全员施加；部分验证偏倚 | STARD 2015 |
| 预后 / 队列 | 混杂调整；事件数；随访丢失；时间偏倚（immortal time） | STROBE、TRIPOD |
| 干预试验 | 随机化与隐藏；盲法；主要终点是否预注册；意向治疗 | CONSORT |
| 仿真 / 体模 | 仿真去掉了哪些真实因素；生成模型与被测方法是否共享先验；结果能推到在体多远 | 无统一规范，按领域惯例 |
| 叙述综述 | 选文是否有偏；是否区分了不同证据层次；结论是否超出被综述的研究 | 无强制规范（不按系统综述的标准苛求） |
| 系统综述 / Meta 分析 | 检索与筛选可重复性；偏倚风险评估；异质性处理 | PRISMA 2020 |

## 不要错用尺子

- 不用 RCT 的标准苛求探索性方法论文没有随机化。
- 不用系统综述的标准苛求叙述综述没有 PRISMA 流程图；但叙述综述若自称"系统"，就按系统的标准看。
- 仿真研究的优势是有真值，局限是真实性；不要只批评一边。
- 小样本的可行性研究，问题是"结论是否写成了确证性的"，而不是"样本小"本身。
