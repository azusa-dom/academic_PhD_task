# academic_phd_task

Research workspace for ongoing PhD work, set up from a Claude research-workflow
handoff package (imported 2026-10-09).

## Layout

- `CLAUDE.md` — collaboration rules and working conventions for Claude Code in this repo.
- `docs/handoff/` — workflow handoff documentation:
  - `00_导入Claude说明.md` — import instructions (web/desktop/Claude Code).
  - `01_我的科研工作流与当前状态.md` — research workflow and current project status.
  - `02_Skills与工具清单.md` — skills and tooling inventory.
  - `03_软件包与计算环境.md` — software packages and compute environment (Python, MATLAB, LaTeX, CSF3, etc.).
  - `evidence/` — status files and execution logs backing the handoff claims.
  - `PROVENANCE.json`, `MANIFEST.sha256` — provenance and integrity records for the imported package.
  - `source_notices/` — upstream license/attribution notices for third-party skill material.
- `.claude/skills/` — the 24 project skills covering literature search/review, writing,
  figure/visualization workflows, and submission preparation (see
  `docs/handoff/02_Skills与工具清单.md` for the full routing table).

No MRI/DICOM data, credentials, `.env` files, or virtual environments are included in this import.
