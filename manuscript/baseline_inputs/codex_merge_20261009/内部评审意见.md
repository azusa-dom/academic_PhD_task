# 作者请求下的内部评审式意见

这份意见针对本次合并稿，由同一 AI 辅助写作流程产生，属于作者侧编辑与方法批评。它不是独立专家审稿，不代表 JCMR 编辑决定，也不能替代人工来源核验。本文的 internal review model 是对作者可见的 transparent process；JCMR 正式审稿模型没有在本次核实。

文章现在能够按算法的方法假设和验证目标组织文献，核心问题与范围一致。最有价值的论证是把 correspondence 与 strain convention 分开，并将实证结果放回其输入、参考、群体和聚合层次。改稿保留了 DENSE 监督与部分 circumferential reference agreement 的正面证据，因此结论没有因强调验证边界而泛化为“cine 无法测量应变”。

**主要意见 1：近期方法的实验协议仍需全文核查。** 37 个纳入来源主要使用摘要或官方资源描述，部分网络的 split、baseline tuning、manual assistance、EPE reference 和 strain implementation 尚未完整提取。正文已限制其结论，并在矩阵写作“not inspected”，但投稿前仍需优先核查 CardioMorphNet、latent ODE、distance-map/memory、IG-BiReg、FE-DIC/DVC 以及 Fourier-Net+ 的完整协议。不能因为摘要未列某个实验而断言整篇文章没有该实验。

**主要意见 2：覆盖广度与复现性应保持当前的真实定位。** 种子阅读集来自两稿，新的搜索有 retmax 与 bounded-feed 限制；初始广义 PubMed 请求的完整参数未保存在导出文件中。文章没有继承 PRISMA 数字，也没有声称 exhaustive retrieval。这一叙述性方法综述定位合适。若将来改为系统性综述，需要另行形成可复现检索、筛选与独立人工流程，而不是把当前日志重新命名。

**主要意见 3：人群与评价单位必须在终审中继续保持分离。** StrainNet 的 DENSE-input displacement error 与 59 人 cine strain comparison 已拆开，DeepStrain 的 CarSON、CarMEN 与 CMAC 也已分别解释。后续压缩文字或换表时，不能再次合并这些分母。虚拟 subject、模板、真实 participant、slice、segment 和 frame 各有不同的独立性，表中报告的数值应保留其单位。

**主要意见 4：区域恢复计划属于方法建议。** Capacity projection、synthetic recovery、human transfer 的三层路线逻辑成立，但本文没有证明某个新“条件可恢复性”指标。定位、范围、spillover 和 peak timing 的具体阈值也未获验证。终审应继续将这些内容表述为可检验实验设计，而非本文的实证发现或新的临床决策规则。

**主要意见 5：投稿前的篇幅、图件归属与声明未完成。** 图中内容是原稿已有概念示意，已查实际渲染并修正图注；作者仍需确认源图权利与投稿披露。当前引用格式是工作用 numeric style，不能等同于 JCMR 官方模板。文章具体字数可在 QA 记录中查看，应在科学内容与全文核查稳定后按照最新栏目要求压缩。作者身份、贡献、资金与利益冲突需要真实作者填报。

**已在本轮解决的关键问题。** Fourier-Net+ 的 cardiac evaluation 被正确恢复；MRXCAT2.0 的平均误差没有被误用为 focal recovery；Jahromi 的等效性结果保留 slice-wise endpoint 与 healthy population；Brandt 的 timing evaluation 被承认；重建证据保留了输入改进与 downstream strain 改变的双向结果。数学例子与经验数据、统计 repeatability 与临床 meaningful change 也已经分开。

这份稿件适合进入作者逐条查源和导师科学审阅。当前内审不作“可投稿”判断：机械排版/引用检查与人工作业是不同状态。上述未完成项记录在交付包中，未被改写为已验证。
