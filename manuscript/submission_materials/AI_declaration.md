# Draft declaration of generative AI and AI-assisted technologies

OpenAI Codex was used to assist with targeted literature-query preparation, bibliographic and primary-source checks, evidence structuring, manuscript and table revision, language editing, LaTeX preparation and deterministic quality assurance. No raw cardiac image was processed and no new experimental measurement or patient data were generated. Claude Code (Anthropic) was subsequently used to merge the v8.1 and v9 drafts, restore the method-lineage and prescribed-focal-test content with their previously verified references, adopt corrections identified by an independently merged draft, add cross-references and Supplementary Table S3, re-verify all reference metadata against Crossref, arXiv and DataCite, and run LaTeX, BibTeX and static consistency checks. Editable sources, data files and render audits accompany the figures.
