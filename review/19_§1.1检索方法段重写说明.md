# §1.1 检索方法段重写说明(2026-10-09)

## 诊断

旧 §1.1 把三类内容挤在一段:综述方法、内部检索审计记录、方法缺陷自述。追查记录后发现根源:那串数字(18 组、281→253→21、23 条/22 项研究)来自 v8.1 的一次**缺口审计**(`supplementary/historical/search-record.md`,标题即 "Bounded gap-search record"),目的是查有没有研究已经把"预设局灶异常 + 已知运动 + 可控估计器扰动"做在一起。它不是综述语料的筛选流程;综述语料主要来自核心文献的前后向引文扩展加人工补充的官方记录(同一文件 "Citation expansion and manual supplementation" 一节)。旧段把审计计数写成了综述的纳入流程,所以读起来像交接日志,也会让审稿人按 systematic review 的标准追问每一步。

## 改法

依据 `medical-imaging-review` 的 narrative-review 方法记录要求(范围、截止、选择依据、来源与检索细节、claim 级核验、证据与解释分开)和 `paper-polish` 的句式规则,把内容拆到两处:

- **正文 §1.1**(两段):第一段写综述问题与语料三步来源(核心集与引文扩展;三库六概念族结构化检索及其目的;10 月 8 日核验更新)。第二段写三项限制(检索边界与两处 "did not identify" 的适用范围;单轮筛选、软件辅助、作者负责;阅读深度按来源角色不同)。正文不再出现计数。第三段(六个比较轴)保留,主语改为 "The studies discussed in Sections 3 to 6"。
- **补充 Methods**:改为六个小节(Review type / Core set and citation expansion / Structured search / Screening and retention / Verification update / Reading depth / Software assistance),计数全部在此,每一步给出操作与标准。
- `main.tex`:数据声明句改为 "these materials document the narrative search and verification described in Section 1.1 and the Supplementary Methods";AI 声明中 Codex 的职责改为 "query execution, deduplication and screening suggestions for the structured search described in Section 1.1"。
